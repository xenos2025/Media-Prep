# Support

## How to get help

1. Read [docs/INSTALLATION.md](docs/INSTALLATION.md) and
   [docs/TROUBLESHOOTING.md](docs/TROUBLESHOOTING.md).
2. Search existing GitHub Issues.
3. Open a new issue with:
   - OS and Python version (`python --version`)
   - Whether you used `pip install -e .` or the skill script path
   - Command run and stderr (redact paths that contain client names if needed)
   - For video: `ffmpeg -version` / `ffprobe -version` snippet

## What we can help with

- Installing the skill or `python -m media_prep`
- Interpreting inspect / process maps, contact sheets, and summary JSON
- Bugs in `media_prep.py` defaults, profiles, or installers

## What we cannot commit to

- Free consulting to process a full store catalog
- Guaranteed review of every naming map you publish
- Hosting or SaaS SLA (this is an open-source local workbench)
- Shopify Admin uploads or theme changes (out of scope by default)
